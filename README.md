# zedcord

discord, but it's [zed](https://zed.dev)-themed. discord announced they're moving to [gpui](https://www.gpui.rs), zed's ui framework, so i figured it should look the part. built on [midnight](https://github.com/refact0r/midnight-discord).

<img src="https://raw.githubusercontent.com/refact0r/zedcord/main/assets/compare/one-dark.png">

## install

### vencord/betterdiscord (or any client that supports theme files)

1. download the theme file, [`zedcord.theme.css`](https://github.com/refact0r/zedcord/blob/main/theme/zedcord.theme.css). (there should be a download button at the top right of the page) for another zed theme, use its file from [`theme/flavors`](https://github.com/refact0r/zedcord/tree/main/theme/flavors) instead: [rosé pine](https://github.com/refact0r/zedcord/blob/main/theme/flavors/zedcord-rose-pine.theme.css), [ayu dark](https://github.com/refact0r/zedcord/blob/main/theme/flavors/zedcord-ayu-dark.theme.css), [gruvbox dark](https://github.com/refact0r/zedcord/blob/main/theme/flavors/zedcord-gruvbox-dark.theme.css) or [catppuccin mocha](https://github.com/refact0r/zedcord/blob/main/theme/flavors/zedcord-catppuccin-mocha.theme.css).
2. drag `zedcord.theme.css` into your theme folder. (there should be a button to open the theme folder in theme settings)
3. (optional) customize the theme by opening `zedcord.theme.css` and editing the CSS variables within.

### install through link

add `https://refact0r.github.io/zedcord/build/zedcord.css` to your theme import links. the colors live in the theme file, so you will need to copy its variables to your quickcss as well.
